# 📄 Monitor de Diário Oficial

Sistema desenvolvido para automatizar o acompanhamento de publicações em Diários Oficiais, permitindo localizar informações importantes através de buscas por palavras-chave.

O objetivo do projeto é reduzir o trabalho manual de consulta diária, facilitando o acompanhamento de publicações como nomeações, contratos, licitações, comunicados e outros atos oficiais.

---

## 🚀 Funcionalidades

* ✅ Monitoramento de Diários Oficiais
* ✅ Busca por palavras-chave personalizadas
* ✅ Identificação de novas publicações
* ✅ Organização das informações encontradas
* ✅ Automação de consultas repetitivas
* ✅ Estrutura preparada para futuras melhorias e integrações

---

## 🎯 Sobre o Projeto

Diários Oficiais possuem uma grande quantidade de informações publicadas diariamente, tornando difícil acompanhar manualmente todos os documentos.

Este projeto nasceu com o objetivo de criar uma ferramenta capaz de:

* Automatizar consultas;
* Encontrar informações relevantes rapidamente;
* Reduzir o tempo gasto em pesquisas manuais;
* Facilitar o acompanhamento de publicações específicas.

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/jcsjulio/Monitor-de-diario-oficial.git
```

Acesse a pasta do projeto:

```bash
cd Monitor-de-diario-oficial
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o sistema:

```bash
python main.py
```

---

## 📌 Exemplo de Busca

O sistema pode ser configurado para acompanhar termos específicos, como:

```
licitação
contrato
nomeação
concurso
prefeitura
saúde
```

Ao encontrar novas publicações relacionadas, o sistema poderá informar os resultados encontrados.
